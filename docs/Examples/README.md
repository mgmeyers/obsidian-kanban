Example boards for trying features out in the test vault.

- [[Auto-move completed cards]] — checking a card's checkbox moves it to the
  `Done` list. Open it as a Kanban board, make sure `Display card checkbox` is
  on, and tick something.

The recurring cards need the [Tasks](https://publish.obsidian.md/tasks/) plugin
to do anything interesting: without it they're ordinary cards, with it ticking
one leaves the next occurrence behind in `Todo` and sends the completed
occurrence to `Done`.
